# refino（引擎）

Constraint Refinement Graph (CRG) 引擎：解析、校验、查询和创建存储在 `.refino/` 目录中的节点。概念模型见 [docs/crg.md](../../docs/crg.md)。

## 存储布局

图以纯文本文件存储，适合版本化：

```
.refino/
├── premises/      # 前提节点：已确认的项目事实
└── constraints/   # 约束节点：限制后续选择空间的项目决策
```

节点的类型由其所在目录决定，不存在于文件内容中。引擎是读写这一存储格式的唯一入口。

## 节点身份（ID）

- ID 即节点文件名主干（去除 `.md` 后缀），是节点的唯一身份，文件内容中不记录 ID。
- ID 是随机 8 字符 Crockford base32（`0-9`、`A-Z`，排除 `I`、`L`、`O`、`U`）。
- ID 由引擎在创建节点时生成，并保证在图内唯一。

## 文件内容

节点文件是 Markdown：

- 正文是节点的内容，其第一段（折叠空白）派生为摘要，供遍历时快速判断相关性；摘要超过 100 字符时截断并追加 `...`。
- frontmatter 是可选的元数据层：没有元数据的文件可以完全没有 `---` 块，空的 `---\n---` 块同样合法。
- 约束节点可附带 `grounds`（依据 id 列表）与 `rationale`（决策理由）；前提节点可附带 `confirmed`（确认时间，RFC 3339 且必须带显式时区偏移）。
- 理由是独立且可选的属性，不承担摘要功能；未知字段被静默忽略，为向前兼容留出空间。

完整的字段定义、校验规则与错误码以源码实现为准（`src/types.ts`、`src/parser.ts`）。

# @refino/cli 设计

引擎本身不包含任何 CLI 逻辑；本包是 `refino` 命令的薄封装，所有图操作均委托给存储层与引擎完成。

## 职责边界

本包提供：

- 命令行参数解析与输出格式化；具体命令、参数与输出以 `--help` 与 `refino guide` 为准（guide 是面向 agent 的自文档命令，文本单一来源在代码中、随 CLI 一同演进，不访问图、不要求 `.refino/` 存在）
- 读取语义：图存在校验问题时，查询命令拒绝执行（结果将有歧义），并以 `validate` 的格式输出问题详情
- 写入前校验：grounds 写入经存储层统一校验，非法即拒绝；写入命令成功后报告受影响下游，供人工复核
- 自定义项目根目录
- `refino web` 的 HTTP 服务：进程内常驻索引、画布按需查询、分页搜索、文件监听与 SSE 变更推送；契约见 [docs/design.md](../../docs/design.md) 的"Web 界面"一节

本包不提供：

- 图结构解析、校验或查询逻辑（由引擎提供）
- 任务界定的图逻辑（授权上下文校验、冻结区、越界报告由 `@refino/harness` 提供，供工具插件消费）
- 可视化编辑界面组件（由 `@refino/ui` 提供）
- agent 会话的任何持久状态：CLI 是一次性进程，会话内签发、已知集与待审查集等会话状态由各工具插件承载

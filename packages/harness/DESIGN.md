# @refino/harness 设计

任务界定层与 vibe coding 工具插件的公共逻辑，平台无关：主入口保持浏览器安全，Node 专属能力经独立子路径导出。

## 职责边界

本包提供：

- 授权上下文与冻结区：冻结区 = 指定的冻结决策沿依据连同其全部祖先节点（未显式指定时默认取全部根决策及其祖先）；修改空间是冻结区的补集，沿细化方向向下封闭，修改空间内的下游修复不可能触及冻结区，写入因此无需波及检测。目标位于冻结区内即拒绝并产出结构化升级报告，冻结区以外可自行修改
- 冻结区交互原语：冻结前沿（冻结区的最小表示）与可冻结决策候选；具体界面展示不在本包职责内
- 签发授权文档：签发文档的单一 schema 与解析（只含冻结前沿——锚点是注入策略参数，不进入签发文档）、默认授权上下文的物化、读取侧按当前图收敛（被删节点剔除、前沿归约为最小表示）、签发预览（冻结计数、解冻根决策警告）
- 编排者凭据解析（Node 专属子路径）：环境变量指向的凭据文件读取与解析；对话签发属插件形态自持，不进入本包
- 待审查派生：前提（或决策）变化后直接依赖它们的决策集合，内存计算、不持久化
- 上下文渲染与注入协议：稳定标识的上下文块（锚点、全部前提与冻结区，summary 级）、冻结与探索标注（探索标注一律使用引擎派生的生效状态，不携带存储标记的下游同样标注）、协议声明文本、注入规模估算、增量 delta 事件（prompt-cache 友好）
- 工具插件公共核心（Node 专属子路径）：会话工作区（基于存储层 Store：常驻投影 + 授权上下文收敛 + 外部变更同步）、delta 降噪、会话开局授权解析（编排者凭据 → 默认值）、DLG 工具执行核心（只读查询、写入链、对话签发；批量 + 部分成功语义；写入链 = 引擎 grounds 校验 + 冻结区判定，越界返回结构化升级报告作为正常结果）、注入文本渲染（初始上下文、超预算引导、resume 状态行、更新通知；工具指称参数化，不硬编码宿主前缀）、canonical 结果形状与渲染

本包不提供：

- 图的解析、存储与文件读写（由 `@refino/storage` 承担）
- 命令行接口、可视化组件（由 `@refino/ui` 承担）
- 具体工具宿主的接入实现（由各适配插件承担，包名遵循各宿主生态的插件命名约定，登记见 docs/design.md"命名约定"）

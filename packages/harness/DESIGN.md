# @refino/harness 设计

任务上下文与 vibe coding 工具插件的公共逻辑，平台无关：主入口保持浏览器安全，Node 专属能力经独立子路径导出。

## 职责边界

本包提供：

- 任务上下文：作用域锚点（任务开始时加载的节点；图在自动锚点预算内时默认覆盖全图，超出则不给基线上下文，由宿主注入极简引导）；锚点随图变化重算，增删以 delta 事件表达
- 待审查派生：前提（或决策）变化后直接依赖它们的决策集合，内存计算、不持久化
- 待复核派生：决策按最后复核时间、前提按最后确认时间计算年龄，分成超期与从未复核两组；不读内容，纯常驻字段投影
- 上下文渲染与注入协议：稳定标识的上下文块（summary 级）、探索标注（一律使用引擎派生的生效状态，不携带存储标记的下游同样标注）、协议声明文本、增量 delta 事件（prompt-cache 友好）
- 工具插件公共核心（Node 专属子路径）：会话工作区（基于存储层 Store：常驻投影、锚点重算、外部变更同步）、delta 降噪、DLG 工具执行核心（只读查询、写入链、待复核查询；批量 + 部分成功语义；写入链 = 引擎 grounds 校验）、注入文本渲染（初始上下文、超预算引导、更新通知；工具指称参数化，不硬编码宿主前缀）、canonical 结果形状与渲染

本包不提供：

- 图的解析、存储与文件读写（由 `@refino/storage` 承担）
- 命令行接口、可视化组件（由 `refino` 与 `@refino/ui` 承担）
- 具体工具宿主的接入实现（由各适配插件承担，包名遵循各宿主生态的插件命名约定）

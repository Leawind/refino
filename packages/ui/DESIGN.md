# @refino/ui 设计

## 职责边界

本包提供：

- DLG 可视化与编辑的 Vue 3 组件
- 可嵌入的编辑器应用壳

组装方式：界面状态经工厂创建，数据通道经客户端接口注入。默认入口用 HTTP 组装整个应用壳（构建产物为纯本地静态资源，由 `refino web` 托管）；嵌入宿主（工具插件、VSCode webview、桌面应用）提供自己的客户端实现并自行注入。

本包不提供：

- 图结构解析、校验或查询逻辑（由引擎提供）
- HTTP 服务与数据存取（由宿主提供）

## 界面设计（`refino web`）

组件库 Naive UI（选型依据见 docs/design.md"技术选型"），图标用内联 SVG，不引外部字体；所有资源本地打包，完全离线可用。

### 通用能力

- **国际化**：界面文案全部经过 i18n，目前支持中文与 English。
- **主题**：支持明暗主题切换。

### 布局

画布是主角：非瞬态的细节面不允许推挤画布，只能覆盖（浮层）或作为同高的列与画布并排。界面按"在哪里 / 是什么 / 怎么连"三种问题分工，每块只有一个职责，同一信息不在两处重复呈现。

- **顶部不再有导航栏**。logo、审阅铃铛、主题开关、系统菜单（命令面板、刷新、快捷键帮助、语言）与收起按钮收进左栏头部的一行；它们都是设置类操作，不该占据画布上方的一条带。
- **左栏·查找**：回答"在哪里"。顶部是身份与全局入口，其下依次为搜索框、范围筛选（全部 / 决策 / 前提 / 未被引用的前提）与分页节点列表，底部固定新建决策与新建前提两个入口。列宽可拖拽调整、可收起为图标轨（图标轨仍能展开并直接聚焦搜索）。不提供"浮动侧栏"模式：面板只有列内一个位置。行点击选中、双击打开编辑面板、按住 Alt 悬停速览；行内不再展开编辑器。
- **中栏·画布**：DLG 的交互式可视化区域，全高全宽，详见下节。画布边缘的浮动控件为自包含组件，覆盖画布而不推挤，且一律不透明——画布内容不得透过控件或按钮显示；浮层面板的展开面覆盖于画布与其他浮动控件之上，外部点击或 Esc 收起。右下角的控件沿相交的两条边排布而不堆成并排的两行：角落放切换画布呈现方式的按钮，方形按钮沿右边向上依次排列，宽条控件沿下边向左依次排列，因此每个控件都贴着边缘，画布内部不留悬浮的一排。多选时画布顶边出现有序的**选择轨迹**：每一步是一枚可点击的胶囊（点击使其成为焦点）、可单独移除，末尾固定"清空"。左下角是一条安静的状态行：决策数、截断 / 渲染裁剪告警、校验问题数（可展开问题列表并定位节点）与实时连接状态；指针手势与按键提示不再常驻，改由状态行的帮助按钮与快捷键帮助承载。
- **右栏·节点**：回答"是什么"。聚焦节点的常驻阅读面：类型、摘要、正文（markdown）、理由、依据、下游决策、确认时间与本节点的校验问题；"依据 / 下游决策"逐行可点，直接导航到对应节点。同一栏在编辑时切换为编辑面板。列宽可拖拽调整、可收起为竖排轨；三维视图下整栏隐藏（焦点内容由星图自身承载），只有编辑会话打开时展开。
- **细节三层模型**：节点细节按瞬态性分层呈现——
  1. **速览**：按住 Alt 悬停呈现的只读浮动卡片，零常驻（见"交互"）；
  2. **节点面板**：右栏的常驻阅读面，跟随焦点变化，承担一切"看"的需求；
  3. **编辑面板**：右栏切换成的表单，承接新建、grounds 编辑、冲突与删除重建裁决。单一编辑会话，面板固定在其打开时的节点上，画布焦点变化不会把它悄悄换掉；有未保存修改时请求切换到别的节点，会话停下询问"保存并继续 / 放弃并继续 / 取消"。外部变更按字段合并进表单，冲突与删除的处理规则见 [docs/design.md](../../docs/design.md) 的"编辑冲突处理"。
- **命令面板**：统一入口——节点搜索与全部全局动作；动作来自共享命令注册表（面板、快捷键分发与快捷键帮助同源），已绑定按键的命令在面板中标注按键。
- **审阅抽屉**：按"自上次查看以来"累积变更（标注来源），逐条可定位到画布；纯客户端派生态，不写入图数据。

### 画布

画布渲染工作集中的节点与边，由 WebGL 承担批量绘制；浮动控件、选择轨迹、速览卡、节点面板等仍为 DOM。术语约定：画布指界面中央的交互式可视化组件，视口指画布的屏幕矩形，虚拟空间指布局所在的坐标空间，工作集指当前加载进画布的节点子集。

#### 数据：按需工作集

- 不默认加载全图（项目可能有 10⁶ 量级的决策节点）。启动即从根决策展开至工作集上限，作为画布初始内容；根决策取画布口径——grounds 不含决策节点的决策（见 docs/design.md"画布按需查询"），使顶层决策均落在前提上的图仍有冷启动入口。
- 工作集为**积累式**：每次选择变化，为每个选中节点展开一个"展开块"并入画布，已有内容不清空。展开块 = 锚点上游沿依据闭包到根 ∪ 下游若干代决策 ∪ 强兄弟（共享直接依据的决策，不含自身与前提）及其上游闭包 ∪ 块内全部决策的上游闭包（保证可见边的两端都在块内）。
- 工作集总量超上限时，淘汰未选中节点中最旧访问的，直至回到上限；被淘汰节点保留在缓存中，再次展开即时恢复。截断或淘汰发生时画布给出提示。

#### 布局

支持多种布局（分层、力导向、轨道，可扩展），显示方向可选。布局以"会话"驱动：快照式（分层）一次算完即稳定，收敛式（力导向、轨道）逐帧演化直至稳定。确定性要求同一工作集与同一节点尺寸输出同一布局，平局按 id 定序。节点尺寸与层间距是画布级公共配置，作为布局输入参与间距与碰撞计算。

前提节点没有依据，但其全部结构意义在于支撑哪些决策：三种布局一致地把前提放在其最浅下游决策的上一层的显示位置、横轴聚拢到下游家族旁边；显示层不参与分层传播，工作集内没有下游的前提回落第 0 层。

##### 分层

- 层沿 grounds 方向；相邻层的节点中点大致对齐，下游节点围绕其依据所在行对称展开，不向单侧漂移。
- 层内排序以交点最少为目标；互不连通的子图作为独立分量排布。
- 前提在其下游家族放置完成后第二遍摆放，取下游各行均值就近落位。

##### 力导向

- 物理沙盒式收敛：在全部根节点的上游虚设一个固定锚点，各节点经弹簧悬挂其上；主轴位置由力的平衡涌现，层越深、下游子树越重，悬挂越靠下游。grounds 边为弹簧，节点间保留近距离斥力，卡片重叠由接触力分离；横轴不设指向绝对坐标的力，整图无平移自由度。四个物理系数可经画布配置调节。
- 初始位置取自分层布局；工作集变化时以现布局坐标为种子增量松弛，交互不触发全图重游，选择变化而结构未变时不重排。
- 节点拖拽：拖动中节点固定于指针、邻域随其实时松弛，松开后松弛至重新稳定；被拖节点不受力约束，只把重叠的邻居推开。
- 虚拟根可选显示：仅作展示、不可交互、不进相机包围盒。
- 收敛以稳定为准：所有节点速度低于阈值（力的实际平衡）会话才停止，不以步数或时间决定。

##### 轨道

- 分层骨架 + 层内力导：分层与分层布局一致，每层在主轴上是一条固定轨道线，节点钉在所属层只能沿轨道滑动——保有分层布局的流向可读性，层序却是活的均衡。
- 层内各节点趋于其全部依据（前提则为其下游）的横轴均值，保序刚隙约束分离，被压缩的家族围绕期望均值对称摊开，不向单侧堆叠。
- 拖拽把指针位置投影到所在轨道，节点只能沿轨道被拖动；松开后锚点把一切拉回原位。不设调节系数面板，也不渲染虚拟根。

#### 视口：相机随焦点

- 焦点为有序选择（选择轨迹）的末尾节点。快照式布局（分层）重排后相机补偿焦点的虚拟位移，使焦点的屏幕位置稳定；收敛式布局（力导向、轨道）不做视口跟随——布局本身在移动节点，相机再介入只会叠加噪声。
- 包围盒 = 工作集的并集包围盒，仅用于约束视口：平移不得将其完全移出视口，缩放有最小与最大限制；视口运动平滑趋近，越界平滑回弹。
- 平移 1:1 跟随；滚轮缩放（无需修饰键），锚点可配置为光标处或画面中心。
- **缩放控件条**：右下浮层提供缩小/百分比（点击复位 100%）/放大/适应视图/适应所选；百分比随相机实时刷新。
- **小地图**：左上角浮层的全工作集总览——节点矩形按内容包围盒缩放绘制，视口矩形以主色描边；点击或拖拽将视口居中到对应位置，滚轮缩放；可收起为角标，显示偏好持久化。
- 画布内容一律属于虚拟空间，随视口缩放一同缩放；文本大小另受画布样式设置中的字号倍率调整。
- 点击判定：按下到抬起的移动距离不超过阈值才构成点击，超过视为拖拽平移。
- 节点屏幕高度低于阈值时进入低细节层级：不显示文本，边随之简化。
- 拖拽中的节点绘制于其余节点之上，且不参与渲染预算剔除。

#### 渲染预算

- 渲染规模以"成本单位"而非节点个数封顶：有文本的节点成本高于纯形状节点，边计少量成本。
- 初始预算由视口面积与硬件能力估算；交互期间按帧耗时自适应收缩或放宽；可手动覆盖。
- 超预算时按优先级裁剪：焦点 → 其余选中 → 悬停节点 → 其余按到最近选中节点的距离。

#### 三维视图

画布边缘的视图开关在平面视图与三维视图之间切换，选择持久化；工作集、选择、编辑会话与审阅状态在两个视图间共用。

- **布局**：上下游关系只由空间位置表达：虚拟根在原点，球壳布局给出确定性的初始形状——每一代谱系占一层同心球壳，根决策沿 Fibonacci 球面展开，其余节点继承父节点的方向继续向外——随后由三维力导向实时松弛。每条依据边都是一根弹簧，全部参与受力；节点间的局部斥力撑开星点及其卫星轨道，虚拟根以弹簧锚住根决策，径向约束只保证决策不落到依据的内侧，不把任何节点固定到球壳上。因此稳定后的半径由弹簧链、局部拥挤与汇入浅层依据的合并边共同决定：同代决策的半径相近而不相同，离核心越远仍然越下游。前提不参与受力布局：每个前提像卫星一样沿其宿主决策周围一圈倾斜轨道公转，每个前提各占一圈半径与倾角都略有差别的轨道，轨道互不重合、不共面，且半径远小于代际间距；同一前提被多个决策引用时在每个决策周围各复制一份；没有被工作集内决策引用的前提绕虚拟根公转。卫星公转与依据边的流光是不停的动画，不因聚焦或力模拟停算而暂停；力模拟只在形状未稳定时运行，稳定即停算。同一工作集与同一交互序列输出确定结果，平局按 id 定序。
- **渲染**：虚拟根是中心的一颗小星，不是球体，也不带文字标签，白色核心与小小的光晕就足够表明它的特殊性；悬停与聚焦时它的光晕轻微涨缩，但始终比节点光晕弱得多。它到各根决策有极淡的射线，同样带一道从虚拟根流向根决策的流光，提示树的起点。决策由内层的冷白过渡到外层的冰蓝，深度也由颜色深浅呼应；前提卫星更小、更暗，只有紧致的小光晕，像环绕行星的卫星而不是另一颗主星。背景固定为深空加星场，不随界面主题变化。grounds 边仅连接决策，为直线，上游端暗、下游端亮，并有一道从上游流向下游的流光持续掠过，方向因此能从运动直接读出，不必依赖箭头；节点到核心的距离、径向排列与深度配色仍共同表达上下游。所有依据边始终绘制：族谱边更亮、其余依据边更暗，焦点沿族谱连向父决策的那条边额外提亮，悬停与选中时相关边进一步强调——画面上的每条连线同时就是布局里的一根弹簧。前提的支撑关系由卫星轨道与邻近位置表达，不再绘制前提到决策的连线；聚焦某系统时以极淡的环线提示其前提轨道。悬停与选中以柔和光晕强调，卫星的光晕按卫星尺度收小，深空雾按相机距离弱化远侧星点；光晕的屏幕尺寸随相机靠近按对数增长，不会线性膨胀。
- **交互**：右键拖拽环绕观察；旋转按轨道球（trackball）合成——一次拖拽是绕屏幕内垂直于拖拽方向的轴的转动，越过极点连续、不翻转，星图的"上"方向随转动一同滚动，"适应视图"把上方向复位为竖直；滚轮平滑改变相机到目标中心的距离，每格约四分之一，按住 Ctrl 滚轮改为平滑调整视场角（FOV）、相机距离不变（视场角以水平与垂直中较小的一轴计量，可调范围 40°–120°），中键拖拽不缩放；触摸时单指拖拽旋转，双指捏合按两指间距缩放相机距离；左键单击选中，并把环绕中心平滑移到该节点（Ctrl/Cmd 切换、Shift 范围选择；点击空处不改变中心），左键拖拽决策节点时它在过按下位置的视平面内移动、受力网络实时响应，拖动期间环绕中心不跟随；单击虚拟根清空选择并把中心移回原点，悬停虚拟根为手型光标；双击打开编辑面板，右键未拖拽时打开上下文菜单；悬停仅在星侧呈现一条摘要标签（横线在上、引线连星，无方框、无类型前缀），悬停的星以正常字号显示、不随距离缩小；按住 Alt 在该标签的横线下方展开正文（可滚动），三维视图不挂载跟随光标的速览卡；悬停与选中的光晕大小平滑过渡。缩放入口与快捷键沿用视口桥：缩放改变相机距离，适应视图回到全工作集并把环绕中心移回虚拟根，适应所选把相机中心移到所选节点，只选一个时其内容继续浮现；右下角的视场角按钮展开滑杆，调整同一角度。左栏查找、选择轨迹、命令面板与审阅抽屉的定位同样把环绕中心移到对应星；右栏节点面板在三维视图中隐藏（编辑会话打开时除外）。小地图与布局、节点尺寸、样式等平面专属控件在三维视图中隐藏。
- **聚焦内容**：环绕中心落到某颗星后，它的摘要与正文浮现在画面的一处空白里——不画背景、不画边框，只用一条横线把内容分成两半：摘要横线上方，正文（markdown）横线下方。一条细线从横线靠星的一端引出、止于星的辉光之外，不接触星本身。空白处由画面中星点的疏密决定：星点、卫星与画布边缘的控件都要避开，内容块整体落在星的一侧，宽度在若干档位中取容得下且尽量宽的一档，因此空白是横条时内容摊宽、是竖缝时内容收窄；正文超出可容纳高度时在块内滚动，指针在其上时滚轮滚动正文而不缩放视图。除悬停的星外，只有聚焦星的直接父决策与它所依据的前提才在星的外侧显示摘要；聚焦星自身的摘要由主内容块承载，其余星保持安静。前提在三维视图里是"一节点多行星"：同一前提在引用它的每个决策周围各有一颗，只有落在聚焦星周围（即聚焦决策所依据）的那些行星带摘要，它绕着别的决策转的副本不算聚焦星的依据、不显示摘要；聚焦某颗前提行星时，它的"父"是承载它的那颗决策。摘要与主内容同款的引线和横线，摘要在横线上方，无背景无边框、没有正文；字号由该星到相机的距离决定，正常大小为上限、无下限，远处更小。摘要随画面变化持续跟随，彼此及主内容块互不遮挡。视角转动、缩放与卫星公转都会改变空白，内容块与引线随之平滑移动，不会跳变；环绕中心离开星（适应视图、点击虚拟根等）时内容与引线一并消失。
- 三维视图用 three.js 绘制，随视图切换按需加载，不进入首屏包体。

#### 显示规则与样式

- 默认显示决策节点与其间的 grounds 边。前提节点作为可开关的"事实层"显示：胶囊形、虚线边、弱化配色，悬停决策时其前提依据边一并强调。
- 不显示节点 ID；除画布外，各列表呈现面也不显示，ID 只出现在节点面板的页脚与速览卡。
- 节点为圆角矩形，摘要文本自动换行填满卡片宽度，行数超出可容纳高度时末行省略号截断；完整内容可经节点面板与速览卡查看。
- 边自带方向箭头，由依据指向决策，端点止于节点边界；悬停、选中的节点及其直接依据边以描边强调；三种状态仅以边框区分，节点内不绘制角标或圆点。
- 画布不对探索中决策作视觉区分（连同左栏查找的探索状态筛选列为后继课题）；探索状态目前呈现于节点面板与速览卡。

#### 交互

- **速览**：按住 Alt 悬停各呈现面（画布节点、左栏查找行、选择轨迹条目等）弹出只读浮卡——缓存的摘要立即显示，全量字段异步补全（latest-wins），正文按 markdown 渲染，依据逐条呈现摘要（不显示依据 id）。卡片形状由内容与页面决定、与光标位置无关，位置贴光标、一侧空间不足即翻转；卡片不可交互，速览只负责看。松开 Alt、离开节点、开始拖拽或按 Esc 即消失。
- **选择**：左键单击选中；Ctrl/Cmd+左键切换选中成员；shift+左键范围选择——以焦点与被点击节点为端点，一端是另一端的祖先时选择二者间的全部决策路径，不同分支时选择最短路径上的决策节点，无公共祖先时仅保留被点击节点并提示；shift+左键拖拽空白框选，与既有选择取并集；左键点击空白清空选择（画布保留已积累内容）；双击节点打开编辑面板，双击空白以编辑面板新建决策；Esc 清空选择（画布保留已积累内容）。
- **右键**：右键点击弹出上下文菜单——节点上为打开编辑器、定位、切换选中、以此细化（以该节点为依据预填新建决策）、删除，空白处为新建决策、新建前提、适应视图；右键从节点拖拽到决策节点即把源节点作为其依据直接写入 grounds（预览边跟随指针，落到前提或空白取消；目标节点存在未保存编辑会话时并入该草稿而非直接保存）；右键拖拽空白平移；浏览器原生菜单在画布上不出现。
- **平移与缩放**：左键拖拽空白、中键拖拽、右键拖拽与空格+左键拖拽均平移画布（空格按住期间点击不触发选择）；滚轮缩放；`Shift+1` 适应视图、`Shift+2` 适应所选。
- **快捷键**：全局命令经集中注册表绑定按键（`Ctrl/Cmd+K` 命令面板、`Ctrl/Cmd+=`/`Ctrl/Cmd+-` 缩放、`?` 快捷键帮助等，完整清单见快捷键帮助）；文本输入聚焦、命令面板打开或编辑面板打开时全局快捷键让位，由相应表面独占键盘。Esc 的分层还原（编辑面板 → 面板 → 浮层 → 清空选择）不经注册表，由各表面的自身监听处理。
- **节点尺寸调节**：画布边缘的控件展开为与节点同尺寸的拖拽调整矩形，全部节点实时随之变尺寸，调整停止后布局以现坐标为种子温和重排；尺寸持久化。
- 选择轨迹有序、不重复，支持点击定位、移除与清空。

#### 配置项

缩放锚点、下游代数、工作集上限、渲染预算（自动/手动）、视图（平面/三维）、布局方式与方向、层间距、显示兄弟节点、前提事实层、文本大小、节点尺寸、力导向调节系数、虚拟根显示开关、小地图显示开关；画布配置与主题、语言偏好一样持久化。

### 编辑功能

单一编辑会话，一个表面：右栏的编辑面板。会话显式进入、显式离开；画布焦点在会话进行中怎么变都不会把它换掉。关闭（返回、取消、Esc）即丢弃修改，有修改时先请求确认；会话有工作时请求切换到别的节点，先停下等"保存并继续 / 放弃并继续 / 取消"。没有隐藏草稿：读不到草稿的地方就不会有草稿。

- 创建前提：正文、摘要、确认时间（默认当前时间，可修改）；创建决策：正文、摘要、理由、依据、探索中开关（缺省关），支持"以此细化"用当前选择预填依据。新建同样在编辑面板内完成，画布全程可见。
- 类型与 id 不可修改。保存 payload 对决策始终显式携带探索中布尔值——整体替换式更新省略该字段即转正，不可静默。
- **grounds 编辑**：当前依据逐行呈现摘要（不显示依据 id），可移除；追加走远程搜索选择；按住 Alt 悬停依据行可速览。画布上另有右键拖拽连边手势直接追加依据（见"交互"）。
- **删除**：编辑面板底部的删除、上下文菜单与 Delete/Backspace 键（作用于焦点节点）共用同一套流程——存在下游决策时阻止并提示，否则经确认对话框执行。

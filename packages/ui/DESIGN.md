# @refino/ui 设计

## 职责边界

本包提供：

- DLG 可视化与编辑的 Vue 3 组件
- 可嵌入的编辑器应用壳

组装方式：界面状态经 `createWorkspace(client)` 与 `createStore(client, workspace)` 工厂创建，数据通道经 `RefinoClient` 接口注入。默认入口（`main.ts`）用 HTTP 实现组装整个应用壳；嵌入宿主（工具插件、VSCode webview、桌面应用）提供自己的 `RefinoClient` 实现并自行 provide 三个注入键（`clientKey`、`workspaceKey`、`storeKey`）。

本包不提供：

- 图结构解析、校验或查询逻辑（由 `refino` 引擎提供）
- HTTP 服务与数据存取（由宿主提供）

## 开发

启动带热更新的开发服务（保存源码后浏览器实时刷新）：

```sh
pnpm --filter @refino/ui dev
```

默认在 <http://localhost:5173> 打开。开发服务会将 `/api/*` 请求代理到后端；后端即 `refino web` 服务（默认 `127.0.0.1:5649`），可用 `--host` / `--port` 指定，或通过环境变量 `REFINO_WEB_HOST` / `REFINO_WEB_PORT` 告知代理目标：

```sh
refino web                       # 终端 1：启动后端
pnpm --filter @refino/ui dev     # 终端 2：启动开发服务
```

构建产物为 `dist/` 下的纯本地静态资源（可完全离线运行），由 `refino web` 托管：

```sh
pnpm --filter @refino/ui build
```

## 界面设计（`refino web`）

组件库 Naive UI（技术选型依据见 docs/design.md“Web 界面”的“技术选型”），图标用内联 SVG，不引外部字体；所有资源本地打包，完全离线可用。

### 通用能力

- **国际化**：界面文案全部经过 i18n，目前支持中文与 English。
- **主题**：支持明暗主题切换，基于 Naive UI 的亮/暗主题与 `themeOverrides`。

### 布局

画布最大化是第一布局原则：非瞬态的细节面不允许推挤画布，只能覆盖（浮层）或暂存（模态）。

- **顶部导航栏**：项目 logo、标题、命令面板入口、审阅铃铛、刷新按钮、设置按钮等全局操作。
- **左侧资源浏览器**：全部节点（决策与前提）统一列表，顶部为搜索框与类型筛选（全部 / 决策 / 前提），并提供“未被引用的前提”快捷视图（对应 CLI `list --unreferenced`）；宽度按整个界面的百分比调节（拖到最小值以下直接收起），可在嵌入（挤占画布）与浮动（覆盖画布）间切换。列表行支持内联展开编辑（见“编辑功能”）。
- **中间：画布**（DLG 的交互式可视化区域），全高全宽，详见下节。
- 画布边缘的浮动控件（已选择列表、布局切换、节点尺寸、样式设置、底部状态胶囊等）为自包含组件，在静态清单中登记（所在角落 + 组件），由统一渲染器挂载到各角的浮动层，覆盖画布而不推挤；新增浮动控件即新建组件并在清单中登记一行。浮层面板的展开面覆盖呈现于画布与其他浮动控件之上，不改变任何浮动控件的位置；面板一律以外部点击或 Esc 收起。底部状态胶囊展示画布统计与告警（截断 / 裁剪 / issues 计数 / 焦点），issues 计数可点击展开问题列表，每条可定位到节点。
- **细节三层模型**：节点细节按瞬态性分层呈现，取代停靠式详情栏——
  1. **速览**：按住 Alt 悬停节点呈现面，浮动卡片只读预览，零常驻（见“交互”）。
  2. **内联编辑**：资源浏览器行内展开的紧凑表单，单手风琴（至多一行展开；展开行为与面板宽度零耦合）（见“编辑功能”）。
  3. **全量编辑器**：覆盖整个界面的模态视图（保留边距，背景变暗并虚化），承接 grounds 编辑、新建、冲突与删除重建裁决；按 Esc 逐级还原并关闭，关闭后选中状态保留。打开期间外部变更按字段合并进表单，冲突与删除的处理规则见 [docs/design.md](../../docs/design.md) 的“编辑冲突处理”。
- **命令面板**：Ctrl/Cmd+K 唤起，统一入口：节点搜索（id/摘要，走 `/api/search`）与全部全局动作（新建、布局/方向/主题/语言切换、刷新重建等）。
- **审阅抽屉**：顶栏铃铛按“自上次查看以来”累积 SSE 变更（`origin` 标注界面/API 写入与外部文件变更），逐条可定位到画布；纯客户端派生态，不写入图数据。

### 画布

画布渲染工作集中的节点与边，由 WebGL 承担（大量节点与边的批量绘制），浮动控件、已选列表、速览卡、编辑器等仍为 DOM。

为避免术语混淆，下列名词在本文档中含义固定：

| 术语             | 指代                                   |
| ---------------- | -------------------------------------- |
| DLG / 决策谱系图 | 数据模型                               |
| 画布（canvas）   | 界面中央的交互式可视化组件/区域        |
| 视口（viewport） | 变换与包围盒决策计算中，画布的屏幕矩形 |
| 虚拟空间         | 布局所在的坐标空间                     |
| 工作集           | 当前加载进画布的节点子集               |

#### 数据：按需工作集

- 不默认加载全图（项目可能有 10⁶ 量级的决策节点）。启动即**从根决策展开**：以全部根决策为锚点、不限下游代数，按近优先展开至工作集上限，作为画布初始内容（选择仍为空）；种子内容按最旧访问计，后续用户展开的内容会优先保留。根决策取画布口径——grounds 不含决策节点的决策（仅落前提或全无依据均可，见 `docs/design.md`「画布按需查询」），使顶层决策均落在前提上的图仍有冷启动入口。
- 工作集为**积累式**：每次选择变化，为每个选中节点展开一个“展开块”并入画布，已有内容不清空；清空选择（Esc）也保留画布内容。积累的结构经外部变更同步保持新鲜（变更节点的 lite 形状自动刷新）。
  - 展开块 = 锚点上游沿 grounds 到根的全量闭包 ∪ 下游 M 代决策（M 可配置）∪ 强兄弟及其上游闭包 ∪ 块内全部决策的上游闭包（保证可见边的两端都在块内）。
  - 强兄弟 = 与选中节点共享 ≥1 个直接 grounds 的决策节点（不含自身与前提）。兄弟候选按重叠数降序、id 升序截断；兄弟入块时上游同样闭合到根，但不再各自展开下游邻域——想看就点它，积累机制会让结果留下。
- 工作集总量受“工作集上限”决策：并入后超限则淘汰未选中节点中最旧访问的（LRU，选中节点免疫），直至回到上限内；被淘汰节点保留在缓存中，再次展开即时恢复。单块展开超限时服务端按近者优先截断。
- 截断或淘汰发生时画布给出提示（见“交互”底部状态胶囊）。加载与渲染另受渲染预算决策（见下）。

#### 布局

画布支持多种布局方式，可在视图右下的浮动控件中切换，选择与主题、语言一样持久化。布局以"会话"驱动：快照式布局（分层）一次算完即稳定，收敛式布局（力导向、轨道）逐帧演化直至稳定。显示方向可自由选择，默认从左到右，可选从上到下、从右到左、从下到上。

布局按当前实际渲染的子图结构整体计算：分层布局每次从零重算，不保留任何历史坐标；力导向与轨道布局以现布局坐标为种子增量演化（见下）。确定性要求同一工作集与同一节点尺寸输出同一布局，与节点传入顺序无关，平局按 id 定序。节点尺寸是画布级配置（画布全部节点共用一个卡片尺寸，经“交互”中的尺寸调节控件调整），作为布局输入参与间距与碰撞计算。层间距（相邻两层之间的距离）同为画布级配置，各布局共用：每层跨度的主轴距离 = 主轴方向卡长 + 层间距，分层布局按它映射层距，力导向弹簧按它取自然长度，轨道布局按它映射轨道线；调整层间距或力导向系数以现坐标为种子继续松弛，不打乱整体。

前提节点没有依据（在分层计算中恒为第 0 层源点），但其全部结构意义在于它支撑哪些决策：三种布局一致地把前提放在其最浅下游决策的上一层的显示位置（决策的显示层即其分层），横轴聚拢到下游家族旁边。若按第 0 层源点摆放，全部前提会钉死在最上游一条线上，支撑边横跨全图，既制造大量交叉又撑大包围盒。前提的显示层不参与分层传播——决策的分层不受影响；工作集内没有下游的前提回落第 0 层。

##### 分层

- 分层布局（层沿 grounds 方向），布局方式可扩展（如从中心向四周扩散）。
- 相邻层的节点中点大致对齐：下游节点围绕其依据（上游锚点）所在行对称展开，不向单侧漂移。
- 层内排序以交点最少为目标，层间坐标使相邻节点尽量靠近；互不连通的子图作为独立分量排布，占据互不重叠的行区间。
- 前提在分量内全部决策放置完成后第二遍摆放：取其下游各行均值就近落位（同行被占时取最近空行），与下游家族贴邻（见上）。

##### 力导向

- 物理沙盒式收敛：在全部根节点的上游虚设一个虚拟根节点作为共同祖先，将其固定为锚点，各根节点经弹簧连到锚点；所有节点受沿显示方向下游的恒定引力，整张图像悬链一样挂于锚点。主轴位置由力的平衡涌现：层越深、其下游子树越重，悬挂得越靠下游，各层均值沿主轴严格递增。grounds 边为胡克弹簧：劲度系数与该边下游端所在层的节点数成反比（宽层的进入弹簧各自更软，进入该层的总拉力保持恒定），原始长度与边跨越的层数成正比（每层跨度对应“卡长 + 层间距”，随公共层间距配置缩放）；节点间保留近距离斥力（有距离上限，不构成跨全图的载荷），卡片重叠由矩形接触力分离（沿较小重叠轴的刚性速度弹簧，静止时残余重叠不超过亚像素），运动带速度阻尼。横轴不设任何指向绝对坐标的力：横轴归位由弹簧网络汇拢至锚点直线完成，整图不存在平移自由度，长时间按住节点也不会出现全图缓移。引力、摩擦、斥力、弹簧劲度四个系数可经画布配置调节（见“配置项”）。跨层合并边会把子节点拉向其两依据之间，个别边因此沿主轴逆向——这是纯物理平衡的固有形态（物理优先，见上）；流向可读性由层均值递增保证。
- 初始位置取自分层布局，随后逐帧松弛直至稳定。
- 虚拟根可选显示：画布配置控制是否绘制虚拟根节点及其到各根节点的边（默认隐藏）。它仅作展示——弱化样式、不可悬停/拖拽/选中，不进相机包围盒；开关切换即时生效，不触发重松弛。
- 增量演化：工作集变化（展开、收缩、外部变更）时，新会话沿用现布局中已存在节点的坐标作为种子（虚拟根的位置一并继承），仅对新增节点在其依据节点的邻域取初始位置，随后松弛至重新稳定——交互不得触发全图重游；仅首次进入力导向（或无可继承坐标）时做全量松弛。选择变化而图结构未变时不重排、不晃动。
- 前提同样经弹簧挂于锚点：自然长度按其显示层计（支撑决策越深悬挂越深，停在其最浅下游决策的上一层附近），支撑边的弹簧原始长度按显示层跨度计，不按第 0 层源点计（见上）。
- 节点拖拽：左键按住节点可拖动，拖动中节点固定于指针、邻域随其实时松弛（邻域稳定后物理休眠，指针移动即恢复）；松开后解除固定并松弛至重新稳定。被拖节点不参与防重叠机制——固定的它只通过矩形接触力把重叠的邻居推开（纯斥力），自身不被任何力约束。拖动超过点击阈值不触发选中；按住空白处拖拽仍是视口平移。
- 主轴与方向：显示方向 LR/TB/RL/BT 可选，主轴随方向而定；切换方向或布局方式意味着布局整体重构，触发一次全量松弛。
- 收敛以稳定为准：物理步进按固定步长累计，动画速度不改变最终结果；所有节点连续多步速度低于阈值（力的实际平衡）会话才停止，不以步数或时间决定停止。超长弛豫经沉降斜坡渐进加大阻尼，使受约束形态的静止可达；另有远超正常收敛所需步数的防异常挂起保护，仅作兜底。

##### 轨道

- 分层骨架 + 层内力导：层沿 grounds 方向的分层与分层布局完全一致，每层在主轴上是一条固定轨道线（轨道间距 = 主轴方向卡长 + 层间距，随公共层间距配置缩放）；节点被钉在所属层的轨道线上，只能沿轨道滑动，因此整体始终保有分层布局的流向可读性，层序却是活的均衡而非快照。
- 层内松弛：每个节点受力趋于其全部依据横轴坐标的均值（家族围绕上游居中，多依据的合流节点停在两锚之间），前提趋于其下游横轴均值（跟随它所支撑的家族，见上），其余根节点趋于其分层快照槽位；横轴目标独立于当前坐标向锚点持续积分（被间隙钳住的节点也不断收敛，钳制解除后必然滑回原位，拖拽不会留下换位残迹），目标重合的节点按分层快照顺序指派槽位。层内自由节点间由保序刚隙约束分离（最小间隙 = 横轴方向卡长 + 层内间距，恒不重叠），被压缩的家族围绕期望均值对称摊开，不向单侧堆叠。每个松弛步先更新目标、再把节点横轴混合趋近无重叠的层内排列，以最大位移的持续安静判定收敛。
- 增量演化与拖拽：会话沿用现布局中已存在节点的横轴坐标作为种子（主轴坐标按新分层重导出），工作集变化不重 stacking；节点拖拽把指针位置投影到节点所在轨道上，节点只能沿轨道被拖动。被拖节点完全置身层内刚隙约束之外——自身不被钳制、也不构成约束，仅施加横轴斥力：同层邻居被投影出其“卡片 + 最小间隙”邻域（就近一侧先避让并沿同侧链式外推），斥力不改变邻居的目标与排序，松开后锚点把一切拉回原位。
- 收敛与方向：与力导向共用"固定步长 + 持续安静判稳"的收敛纪律；显示方向 LR/TB/RL/BT 可选，主轴随方向而定，切换方向或布局方式触发全量重构。轨道布局不设调节系数面板，也不渲染虚拟根。

#### 视口：相机随焦点

- 焦点为已选择列表的末尾节点。跟随策略按布局类型区分：
  - 快照式布局（分层）重排后，相机平移补偿焦点的虚拟位移，使焦点的屏幕位置保持稳定（点击的节点不因重排而移动）；焦点更换时若新焦点不在视口内，相机平滑飞向并居中；
  - 收敛式布局（力导向、轨道）不做任何视口跟随：布局本身在移动节点，相机再介入只会叠加噪声，视口完全由用户平移/缩放控制。
- 分层布局下，已在视口内的新焦点原位保留（画布上左键单击选中的节点不因点击而移动）。
- 包围盒 = 工作集中所有已布局节点的并集包围盒，仅用于决策视口，不渲染：
  - 平移不得将包围盒完全移出视口；
  - 缩放时包围盒长边的屏幕尺寸不得小于视口短边的一半（构成最小缩放）；最大缩放为可配置上限。
- 平移：左键按住拖拽，画面 1:1 跟随。
- 缩放：滚轮缩放视图（无需修饰键），对缩放倍率使用乘法；缩放锚点可配置为光标处或画面中心。滚轮不得触发页面缩放。
- 画布内容一律属于虚拟空间，随视口缩放一同缩放：节点尺寸与圆角、描边、边线宽度与方向箭头、文本皆是；文本大小另受画布样式设置中的字号倍率调整（10%–300%，无级，显示取整百分比）。
- 点击判定：左键自按下到抬起的移动距离不超过阈值（约 2px）才构成点击；超过阈值视为拖拽平移，不触发点击。
- 视口运动采用目标值平滑趋近；变更结束后包围盒决策在终态校验，越界则平滑回弹。
- 节点屏幕高度低于阈值时进入低细节层级：不显示节点内容（文本），边随之简化。
- 拖拽中的节点绘制于其余节点（含标签）之上，且不参与渲染预算剔除：指针下的卡片被路过卡片遮住或中途消失都读作“抓丢了”。

#### 渲染预算

- 渲染规模以"成本单位"而非节点个数封顶（不同硬件差距大，不写死数量）：有文本的节点成本高于纯形状节点，边计少量成本。
- 初始预算由视口面积与硬件能力估算；交互期间按帧耗时自适应收缩或放宽；可手动覆盖。
- 超预算时按优先级裁剪：焦点 → 其余选中 → 悬停节点 → 其余按到最近选中节点的距离升序保留。

#### 显示规则与样式

- 画布默认显示决策节点与它们之间的 grounds 关系。前提节点作为可开关的“事实层”显示：胶囊形、虚线边、弱化配色，前提 → 决策的边为细虚线，悬停决策时其前提依据边一并强调；弱边在普通边基础上更细一档，并按固定比例向画布背景色预混淡化（较普通边弱一档以上，仍可辨认），虚拟根的边同此弱化样式；开关入画布配置并持久化。前提已随展开块进入工作集，渲染预算按纯形状计低成本，超预算时沿用既有裁剪。
- 不显示节点 ID；节点为圆角矩形。ID 对用户几乎无意义，除画布外，资源浏览器行、已选择列表等列表呈现面也不显示；ID 只出现在详情编辑器头部与速览卡。
- 节点摘要文本自动换行以填满卡片宽度：按宽度换行尽量完整呈现，仅当换行后的行数超出卡片高度可容纳的行数时，才在最后一行以省略号截断；完整内容始终可经速览卡与详情编辑器查看。
- 边自带方向箭头，由依据（上游）指向决策（下游）；边端点止于节点边界。
- 悬停节点：样式高亮（描边颜色与粗细），其直接依据边一并强调。
- 选中节点：主色描边；焦点节点以更粗描边区分。普通、悬停与选中三种状态仅以边框区分，节点内不绘制任何角标或圆点。选中节点之间的 grounds 边以强调样式呈现（同悬停强调）。画布不对探索中（exploring）决策作视觉区分——受“无角标”决策需独立视觉设计，连同资源浏览器的探索状态筛选列为后继课题；探索状态目前呈现于速览卡与详情编辑器。

#### 交互

- 按住 Alt 悬停任意节点呈现面（画布节点、资源浏览器行、已选择列表条目、谱系候选条目；已展开的资源浏览器行除外——它本身就是编辑面）：浮动速览卡只读预览——缓存的 lite 形状立即显示（类型、id、摘要），全量字段经 `GET /api/nodes/:id` 异步补全（正文/理由全文、探索中标记、issues 角标，latest-wins），正文按 markdown 渲染（与编辑器预览一致），依据以无序列表逐条呈现摘要（经 `POST /api/query/grounds` 单跳批量拉取，不显示依据 id）。卡片形状与位置按页面尺寸、光标位置与内容自然大小计算：形状只由内容与页面决定、与光标无关（光标平滑移动时不重排文本）——优先正方形，宽度取使「内容换行后高度与宽度相当」的值（在观感下限与整页宽度上限之间）：矮内容保持自然宽度不硬凑方形，高内容收拢为方形；方形触到整页限制时在另一轴延伸为矩形，代码/表格等不可换行内容在卡内横向滚动，仅当延伸后仍装不下时内容才在卡内滚动。位置默认置于光标右下、与光标保持间距，一侧空间不足即翻转到另一侧；仅当两侧都放不下整卡时才贴较宽一侧的页面边缘（此时可能覆盖光标——卡片不可交互），纵向在内容高于整页限制时贴边，任何时候不越出页面；内容可滚动时滚轮滚动卡内内容而非缩放画布（`pointer-events` 保持 `none`，不可交互——速览只负责看，交互属于选择与编辑器）。松开 Alt、离开节点（约 100ms 宽限）、开始拖拽或按 Esc 即消失；画布上对 Alt keydown `preventDefault` 以抑制浏览器菜单聚焦；输入框聚焦与拖拽期间不触发。
- 左键单击节点（按下到抬起未超出拖拽阈值）：设为唯一选中节点。
- shift+左键：范围选择，清空并替换当前选择。以焦点节点与被点击节点为端点：
  - 一端是另一端的祖先：选择二者之间的全部决策路径；
  - 不同分支：选择二者间最短路径上的决策节点（两端点各自沿 grounds 上行、在最近公共祖先汇合，每侧取一条）；
  - 无公共祖先（确定无关，或预算内无法判定）：仅保留被点击节点并提示。
    被点击节点成为新焦点；空选择时 shift+左键等同左键单击。
- 右键单击节点：切换其选中状态（加入列表末尾或移除）；画布抑制浏览器右键菜单，右键拖拽不平移。
- 双击节点：打开详情栏。
- Esc：清空选择；画布保留已积累的内容（见“数据：按需工作集”）。
- 节点尺寸调节：画布边缘浮层的“⤢”按钮点击后本身展开为与节点同尺寸的圆角矩形（1 虚拟单位 = 1 屏幕像素，即节点在 100% 缩放下的样子），展开的矩形就是调整控件本身：四角提供拖拽手柄，拖任一角调整宽高、对角固定；尺寸下限约与收起的按钮同大，上限钳制；全部节点实时随之变尺寸，调整停止后布局重排（分层直接重算，力导向与轨道以现坐标为种子温和重热，不打乱整体）。Esc 或点击控件外部收起回按钮；“恢复默认”回到参考尺寸。尺寸经画布配置持久化（见“配置项”）。
- 已选择列表有序、不重复，以浮动层展示，支持点击定位、移除与清空。

#### 配置项

缩放锚点模式、下游代数（M）、工作集上限、渲染预算（自动/手动）、布局方式、布局方向、层间距（各布局公共）、显示兄弟节点（默认开启）、前提事实层（默认开启）、文本大小与节点尺寸（画布边缘的浮动控件），以及力导向调节系数——引力、摩擦、斥力、弹簧劲度（画布边缘的“布局调节”面板，力导向系数仅力导向模式下展示），与虚拟根显示开关（默认开启，仅力导向）。画布配置与主题、语言偏好一样经 localStorage 持久化。

### 编辑功能

单一编辑会话，两个表面：内联表单与全量编辑器共享 store 中的草稿状态（base 快照、revision、已改字段），跨表面延续；仅显式重置或切换载入其他节点才丢弃。创建一律走全量编辑器（grounds 编辑需要宽度）。

- 创建 premise：body、summary、confirmed（默认当前时间，可修改）。
- 创建 decision：body、summary、rationale、grounds、exploring（探索中开关，缺省关）；支持“以此细化”——用当前选择预填 grounds。
- 编辑节点：summary、body、rationale、grounds、exploring（仅决策）；类型与 id 不可修改。保存 payload 对决策始终显式携带 exploring 布尔值（含内联表单——整体替换式 PUT 省略该字段即转正，不可静默）。
- **grounds 编辑**（两表面共用同一字段组件）：当前依据以列表逐行呈现，每行一条摘要（不显示依据 id），× 移除，追加走远程搜索选择（经 `/api/search`）；按住 Alt 悬停依据行可速览该依据。
- 编辑器内的谱系区：grounds 与 dependents 可点击定位/选择（显示摘要），祖先面包屑按层，为 grounds 选择提供图上下文。
- **内联展开**（资源浏览器行）：行首箭头展开，展开即选中该节点（与画布选择联动）；单手风琴，至多一行展开，展开另一行或打开编辑器时收起。表单为单列满宽布局，每个属性独占一行（标签在上、输入占满宽度），与编辑器共享字段组件；已展开的行不再触发 Alt 速览：
  - summary 单行；body ≤ 8 行、rationale ≤ 4 行，超出内部滚动，整表单总高有界，动作行不脱出视口；body 带与编辑器一致的 markdown 预览开关。
  - grounds 与编辑器同构（列表逐行、Alt 速览、× 移除、搜索追加）；批量调整引导到编辑器。
  - 动作行：重置 · 在编辑器中打开 · 保存；删除不进内联（破坏性操作留在编辑器）。无隐式提交，Esc 仅收起。
  - 带未保存草稿收起不丢失：行头显示脏标记，重新展开即恢复；同字段冲突与外部删除的裁决不进窄行，行内提示“在编辑器中解决”。
  - 展开行为与面板宽度零耦合：展开/收起不读写面板宽度。
  - 保存反馈就地显示：409 与 grounds 校验失败标注在对应字段下方。

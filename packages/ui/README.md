# @refino/ui

Constraint Refinement Graph（CRG）的可视化组件库与可嵌入编辑器应用壳，基于 Vue 3 实现。

宿主（CLI 的 `refino web` 服务、工具插件、桌面应用、VSCode webview）负责提供容器与数据通道；本包只关注界面本身。

界面定位与后端 API 契约等跨包设计见 [docs/design.md](../../docs/design.md)。

## 界面设计（`refino web`）

组件库 Naive UI，图标用内联 SVG，不引外部字体；所有资源本地打包，完全离线可用。

### 通用能力

- **国际化**：界面文案全部经过 i18n，目前支持中文与 English。
- **主题**：支持明暗主题切换，基于 Naive UI 的亮/暗主题与 `themeOverrides`。

### 布局

画布最大化是第一布局原则：非瞬态的细节面不允许推挤画布，只能覆盖（浮层）或暂存（模态）。

- **顶部导航栏**：项目 logo、标题、命令面板入口、审阅铃铛、刷新按钮、设置按钮等全局操作。
- **左侧资源浏览器**：全部节点（约束与前提）统一列表，顶部为搜索框与类型筛选（全部 / 约束 / 前提），并提供「未被引用的前提」快捷视图（对应 CLI `list --unreferenced`）；宽度按整个界面的百分比调节（拖到最小值以下直接收起），可在嵌入（挤占画布）与浮动（覆盖画布）间切换。列表行支持内联展开编辑（见「编辑功能」）。
- **中间：画布**（CRG 的交互式可视化区域），全高全宽，详见下节。
- 画布边缘的浮动控件（已选择列表、方向切换、底部状态胶囊等）由统一的浮动层组件承载，覆盖画布而不推挤，便于将来增加更多浮动按钮。底部状态胶囊展示画布统计与告警（截断 / 裁剪 / issues 计数 / 焦点），issues 计数可点击展开问题列表，每条可定位到节点。
- **细节三层模型**：节点细节按瞬态性分层呈现，取代停靠式详情栏——
  1. **速览**：按住 Alt 悬停节点呈现面，浮动卡片只读预览，零常驻（见「交互」）。
  2. **内联编辑**：资源浏览器行内展开的紧凑表单，单手风琴（至多一行展开；展开行为与面板宽度零耦合）（见「编辑功能」）。
  3. **全量编辑器**：覆盖整个界面的模态视图（保留边距，背景变暗并虚化），承接 grounds 多选、新建、冲突与删除重建裁决；按 Esc 逐级还原并关闭，关闭后选中状态保留。打开期间外部变更按字段合并进表单，冲突与删除的处理规则见 [docs/design.md](../../docs/design.md) 的「编辑冲突处理」。
- **命令面板**：Ctrl/Cmd+K 唤起，统一入口：节点搜索（id/摘要，走 `/api/search`）与全部全局动作（新建、布局/方向/主题/语言切换、刷新重建等）。
- **项目概览（冷启动空态）**：无选择时画布不空白，渲染根约束摘要卡片（经 `roots` 过滤分页）与项目计数；点击卡片即选中并展开邻域。
- **审阅抽屉**：顶栏铃铛按「自上次查看以来」累积 SSE 变更（`origin` 标注界面/API 写入与外部文件变更），并列出待审查队列；逐条「已复核」标记存于本地偏好（按 id+revision 键，节点再变更自动重新挂起），不写入图数据。

### 画布

画布渲染工作集中的节点与边，由 WebGL 承担（大量节点与边的批量绘制），浮动控件、已选列表、速览卡、编辑器等仍为 DOM。

为避免术语混淆，下列名词在本文档中含义固定：

| 术语             | 指代                                   |
| ---------------- | -------------------------------------- |
| CRG / 约束细化图 | 数据模型                               |
| 画布（canvas）   | 界面中央的交互式可视化组件/区域        |
| 视口（viewport） | 变换与包围盒约束计算中，画布的屏幕矩形 |
| 虚拟空间         | 布局所在的坐标空间                     |
| 工作集           | 当前加载进画布的节点子集               |

#### 数据：按需工作集

- 不默认加载全图（项目可能有 10⁶ 量级约束节点）。初始为项目概览空态（根约束卡片），从资源浏览器或概览选择节点后开始展开。
- 工作集 = 各选中节点的邻域并集 ∪ 范围选择路径节点 ∪ 选中节点的强兄弟集合。
  - 邻域为选中节点向上 N 代祖先、向下 M 代子孙与直接依据，N、M 可配置。
  - 强兄弟 = 与选中节点共享 ≥1 个直接 grounds 的约束节点（不含自身与前提）。兄弟候选按重叠数降序、id 升序排序，受渲染预算截断。兄弟节点同样按 N、M 展开其纵向邻域。
- 节点离开所有选中节点的邻域与兄弟覆盖时移出工作集（保留在缓存中，便于快速恢复）。
- 加载与渲染受渲染预算约束（见下），超预算时按近者优先截断并提示。

#### 布局

画布支持多种布局方式，可在视图右下的浮动控件中切换，选择与主题、语言一样持久化。布局以"会话"驱动：快照式布局（分层）一次算完即稳定，收敛式布局（力导向）逐帧演化直至稳定。显示方向可自由选择，默认从左到右，可选从上到下、从右到左、从下到上（无方向语义的布局忽略方向，方向切换按钮随之禁用）。

布局按当前实际渲染的子图结构整体计算，不保留节点的历史坐标：结构变化后，节点的相对位置始终由当前结构决定，不会因增量拼接而变得奇怪。所有布局确定性：同一工作集输出同一布局，与节点传入顺序无关，平局按 id 定序。

##### 分层

- 分层布局（层沿 grounds 方向），布局方式可扩展（如从中心向四周扩散）。
- 相邻层的节点中点大致对齐：下游节点围绕其依据（上游锚点）所在行对称展开，不向单侧漂移。
- 层内排序以交点最少为目标，层间坐标使相邻节点尽量靠近；互不连通的子图作为独立分量排布，占据互不重叠的行区间。

##### 力导向

- 物理沙盒式收敛：grounds 边施加弹簧力，节点两两之间存在斥力并保证不重叠，另有轻微向心引力；初始位置取自分层布局，随后逐帧松弛直至稳定。
- 收敛过程与帧率无关：物理步进按固定步长累计，动画速度不改变最终结果；存在硬性步数上限，保证必然终止。
- 无方向语义，忽略显示方向选择。

#### 视口：相机随焦点

- 焦点为已选择列表的末尾节点。相机平移补偿焦点因布局重算产生的虚拟位移，使焦点的屏幕位置保持稳定。
- 焦点更换时，已在视口内的新焦点原位保留（画布上左键单击选中的节点不因点击而移动）；视口外或尚未进入场景的新焦点由相机平滑飞向并居中。
- 包围盒 = 工作集中所有已布局节点的并集包围盒，仅用于约束视口，不渲染：
  - 平移不得将包围盒完全移出视口；
  - 缩放时包围盒长边的屏幕尺寸不得小于视口短边的一半（构成最小缩放）；最大缩放为可配置上限。
- 平移：左键按住拖拽，画面 1:1 跟随。
- 缩放：滚轮缩放视图（无需修饰键），对缩放倍率使用乘法；缩放锚点可配置为光标处或画面中心。按住 ctrl 时滚轮仅调整文本的虚拟字号倍率，不改变视口；滚轮不得触发页面缩放。
- 文本与节点圆角属于虚拟空间，随视口缩放一同缩放；文本大小另受 ctrl+滚轮的字号倍率调整。
- 点击判定：左键自按下到抬起的移动距离不超过阈值（约 2px）才构成点击；超过阈值视为拖拽平移，不触发点击。
- 视口运动采用目标值平滑趋近；变更结束后包围盒约束在终态校验，越界则平滑回弹。
- 节点屏幕高度低于阈值时进入低细节层级：不显示节点内容（文本），边随之简化。

#### 渲染预算

- 渲染规模以"成本单位"而非节点个数封顶（不同硬件差距大，不写死数量）：有文本的节点成本高于纯形状节点，边计少量成本。
- 初始预算由视口面积与硬件能力估算；交互期间按帧耗时自适应收缩或放宽；可手动覆盖。
- 超预算时按优先级裁剪：焦点 → 其余选中 → 悬停节点 → 其余按到最近选中节点的距离升序保留。

#### 显示规则与样式

- 画布默认显示约束节点与它们之间的 grounds 关系。前提节点作为可开关的「事实层」显示：胶囊形、虚线边、弱化配色，前提 → 约束的边为细虚线，悬停约束时其前提依据边一并强调；开关入画布配置并持久化。前提已随邻域进入工作集，渲染预算按纯形状计低成本，超预算时沿用既有裁剪。
- 不显示节点 ID；节点为圆角矩形。
- 边自带方向箭头，由依据（上游）指向约束（下游）；边端点止于节点边界。
- 悬停节点：样式高亮（描边颜色与粗细），其直接依据边一并强调。
- 选中节点：主色描边与角标；焦点节点以更粗描边区分。

#### 交互

- 按住 Alt 悬停任意节点呈现面（画布节点、资源浏览器行、已选择列表条目、谱系候选条目）：浮动速览卡只读预览——缓存的 lite 形状立即显示（类型、id、摘要），全量字段经 `GET /api/nodes/:id` 异步补全（正文/理由节选、grounds 计数、issues 角标，latest-wins）。卡片跟随光标、视口内翻转、不遮挡指针下节点，且 `pointer-events: none` 不可交互（速览只负责看，交互属于选择与编辑器）。松开 Alt、离开节点（约 100ms 宽限）、开始拖拽或按 Esc 即消失；画布上对 Alt keydown `preventDefault` 以抑制浏览器菜单聚焦；输入框聚焦与拖拽期间不触发。
- 左键单击节点（按下到抬起未超出拖拽阈值）：设为唯一选中节点。
- shift+左键：范围选择。以焦点节点与被点击节点为端点：
  - 一端是另一端的祖先：选择二者之间的全部约束路径；
  - 不同分支：选择二者各自到最近公共祖先的路径上的约束节点；
  - 预算内找不到公共祖先：仅追加被点击节点并提示。
    结果按序追加到已选择列表末尾，已存在的节点保持原位。
- ctrl+左键：切换节点的选中状态（加入列表末尾或移除）。
- 双击节点：打开详情栏。
- Esc：清空选择。
- 已选择列表有序、不重复，以浮动层展示，支持点击定位、移除与清空。

#### 配置项

缩放锚点模式、邻域代数（N、M）、渲染预算（自动/手动）、布局方式、布局方向、显示兄弟节点（默认开启）、前提事实层（默认开启）。画布配置与主题、语言偏好一样经 localStorage 持久化。

### 编辑功能

单一编辑会话，两个表面：内联表单与全量编辑器共享 store 中的草稿状态（base 快照、revision、已改字段），跨表面延续；仅显式重置或切换载入其他节点才丢弃。创建一律走全量编辑器（grounds 多选需要宽度）。

- 创建 premise：body、summary、confirmed（默认当前时间，可修改）。
- 创建 constraint：body、summary、rationale、grounds（多选节点，支持搜索）；支持「以此细化」——用当前选择预填 grounds。
- 编辑节点：summary、body、rationale、grounds；类型与 id 不可修改。
- 编辑器内的谱系区：grounds 与 dependents 可点击定位/选择，祖先面包屑按层，为 grounds 选择提供图上下文。
- **内联展开**（资源浏览器行）：行首箭头展开，展开即选中该节点（与画布选择联动）；单手风琴，至多一行展开，展开另一行或打开编辑器时收起。表单为单列满宽布局，每个属性独占一行（标签在上、输入占满宽度），与编辑器共享字段组件：
  - summary 单行；body ≤ 8 行、rationale ≤ 4 行，超出内部滚动，整表单总高有界，动作行不脱出视口。
  - grounds 以 chips 满宽换行，× 移除，追加走紧凑搜索弹层；批量调整引导到编辑器。
  - 动作行：重置 · 在编辑器中打开 · 保存；删除不进内联（破坏性操作留在编辑器）。无隐式提交，Esc 仅收起。
  - 带未保存草稿收起不丢失：行头显示脏标记，重新展开即恢复；同字段冲突与外部删除的裁决不进窄行，行内提示「在编辑器中解决」。
  - 展开行为与面板宽度零耦合：展开/收起不读写面板宽度。
  - 保存反馈就地显示：409 与 grounds 校验失败标注在对应字段下方。

## 开发

启动带热更新的开发服务（保存源码后浏览器实时刷新）：

```sh
pnpm --filter @refino/ui dev
```

默认在 <http://localhost:5173> 打开。开发服务会将 `/api/*` 请求代理到后端；后端即 `refino web` 服务（默认 `127.0.0.1:5649`），可用 `--host` / `--port` 指定，或通过环境变量 `REFINO_WEB_HOST` / `REFINO_WEB_PORT` 告知代理目标：

```sh
refino web                       # 终端 1：启动后端
pnpm --filter @refino/ui dev     # 终端 2：启动开发服务
```

构建产物为 `dist/` 下的纯本地静态资源（可完全离线运行），由 `refino web` 托管：

```sh
pnpm --filter @refino/ui build
```

## 职责边界

本包提供：

- CRG 可视化与编辑的 Vue 3 组件
- 可嵌入的编辑器应用壳

组装方式：界面状态经 `createWorkspace(client)` 与 `createStore(client, workspace)` 工厂创建，数据通道经 `RefinoClient` 接口注入。默认入口（`main.ts`）用 HTTP 实现组装整个应用壳；嵌入宿主（工具插件、VSCode webview、桌面应用）提供自己的 `RefinoClient` 实现并自行 provide 三个注入键（`clientKey`、`workspaceKey`、`storeKey`）。

本包不提供：

- 图结构解析、校验或查询逻辑（由 `refino` 引擎提供）
- HTTP 服务与数据存取（由宿主提供）
